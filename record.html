🔴 Opname-sessie

De opname-server (piper-sim-recorder serve) draait op de robot-PC, niet op GitHub Pages. Vul host en token één keer in; ze worden alleen op dit apparaat bewaard (localStorage). Het token gaat via het #fragment naar de sim en komt nooit in een querystring of serverlog.

Vanaf https is wss:// met een geldig certificaat nodig (bv. tailscale serve of Caddy). Alleen host mag ook.
Moet overeenkomen met --cams van de server (standaard front:640x480,top:640x480).
